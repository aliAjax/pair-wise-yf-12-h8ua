# 油站网点地图管理

- 行业：石油
- 技术栈：Vue3、Vite、TypeScript、Element Plus、Leaflet
- 启动：`npm install && npm run dev`
- 构建：`npm run build`

这是一个功能最小闭环前端项目，数据默认保存在浏览器localStorage中，方便后续扩展接口、权限、图表或地图能力。

## 应急保供核销台

页内「应急保供核销台」页签用于三辆保供车（油品/区域/额度）对站点（含保底库存）的提油核销：

- 登记：油品或区域不符、提后低于站点保底、同一车辆已有未完成单、或超出可用额度，均整单拒绝且原数值不动；通过后按申报量冻结额度。
- 取消：未完成单（待提油/待复核）可取消，冻结额度立即解冻，库存不动。
- 完成：实提与申报差两成以内直接核销；超过两成转待复核，额度继续占用，补写差异原因并确认后才扣站点库存与额度。

业务代码按职责分三处，均在 `src/emergency/`：`rules.ts`（纯规则校验与偏差计算）、`status.ts`（单据状态机、额度/库存核算与响应式状态）、`storage.ts`（核销单 localStorage 读写）。核销单存储键为 `hxwlfront-21-emergency-orders`，未新增任何依赖或服务。
